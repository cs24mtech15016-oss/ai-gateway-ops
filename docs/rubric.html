Rubric · single-agent v1

What already exists, and what is new.

Every close method scored against the parameters a single-agent long-horizon router needs, re-checked on 2026-10-26 against each paper’s method and experiment sections. Famous request-level routers are included for reference. Highlighted rows carry the novelty claim, summarised just below. Click any method name in the matrix header for what it does, the problem it targets, how it relates to CPR, and what the paper and code check found.

Where CPR is new

No policy chooses these yet. The Handoff Tax measured them with fixed policies.

D3 + D4Model and packet chosen jointly, by a learned policy

At a checkpoint, pick the receiving model and the handoff packet (full, compact, drop or restart) from execution evidence, and beat the best fixed packet at matched cost.

Strongest claim. The Handoff Tax showed the best packet flips with switch direction, and asked for exactly this adaptive policy as future work.
E2 + A3Switch decisions trained on measured continuation value

Label each stay/switch with paired continuations branched from the same saved agent state, not from full-episode rollouts or a per-switch penalty table.

Moderate. TRACE and PAIR branch from a restored state, but only to judge compaction; TACIT explicitly avoids it.
A4Timing compared in software agents

Fixed-prefix, per-call and adaptive timing on matched states, with reversible switching, packet choice and real dollar costs.

No longer novel alone. TACIT-Switch already ran this comparison (one-way, outside SWE, proxy cost); frame it as an extension.

Not claimed as new: decisions after the first prompt, episode-success training, timing comparison, budget in state, continuity locks, cache-aware cost and handoff interfaces. CPR adopts these from the methods below. The famous request-level routers (RouteLLM, FrugalGPT, Avengers-Pro, and the LiteLLM complexity router this repo uses today) score only on D1: they pick a model per query and keep no session state. They are the cost-saving baselines CPR must beat, not competitors for the novelty claim.
